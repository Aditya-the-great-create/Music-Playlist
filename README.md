🎵 Music Playlist – Python Project
A simple and interactive music playlist manager built in Python.
This project allows users to add songs, delete songs, and view their playlist, helping beginners practice core Python programming concepts.




Features: 
Add new songs to your playlist
Delete existing songs
View the complete playlist
Uses Functions, Classes, and Pandas DataFrames
Beginner-friendly code structure
